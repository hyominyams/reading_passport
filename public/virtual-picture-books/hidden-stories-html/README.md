# 학생용 Hidden Stories HTML 자료

외국어 원문 사이트를 학생에게 직접 노출하지 않고, 핵심 내용을 한국어 기사/학습 자료 형식으로 재구성한 로컬 HTML 자료입니다.

- 대상: 초등 고학년-중등
- 제외 국가: 르완다, 콜롬비아
- 포함 국가: 케냐, 탄자니아, 네팔, 캄보디아
- 앱 연결 상태: 연결하지 않음
- 삭제 방법: `output/virtual-picture-books/hidden-stories-html/` 폴더 전체 삭제

## 파일

- `index.html`: 자료 목록
- `style.css`: 공통 기사형/학습지형 스타일
- `kenya-bees-climate.html`: 케냐, 꿀벌과 기후 변화
- `tanzania-hero-community.html`: 탄자니아, 영웅과 공동체
- `nepal-school-road.html`: 네팔, 산길과 배움의 권리
- `cambodia-mekong-memory.html`: 캄보디아, 메콩강과 기억

## 운영 방식

- 외부 링크는 HTML 안에 넣지 않고 Step2 카드로 별도 등록합니다.
- 학생 본문은 직접 읽을 수 있는 한국어로 새로 작성합니다.
- 외부 문장을 그대로 옮기지 않고, 핵심 개념만 쉬운 문장으로 재구성합니다.
- Hidden Stories 등록 시 URL은 이 HTML 파일의 배포 경로를 사용합니다.
